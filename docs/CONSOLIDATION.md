## 发现与修复

原 `index.html` 实际是 OOXML/Word ZIP 文件（88,209 字节），包含网页源码。此前直接把扩展名改成 HTML 未转换文件格式。

用 Python `zipfile` 读取 `word/document.xml`，按段落拼接 `w:t` 文本，恢复 279 段 HTML 源码。然后将 style、数据数组和交互逻辑拆分到 `assets`，保留原有功能及视觉样式。源 Word 文件仍可从上述历史提交取回。

同时修复：

- 单词、练习、场景循环后的进度越界。
- 练习和游戏共享分数以及游戏重置影响练习成绩。
- 返回页面后再次答同一题可重复加分。
- 对话含单引号时生成的内联朗读事件语法错误；改为 DOM 创建节点并绑定事件。
- 练习答题时选择器影响游戏选项；限定到练习区域。
- 未核实来源的题目不再声称为真题。
